サービス概要

金融・暗号資産・FX・株価・バックテスト・取引履歴などのデータを、Pythonで整形・集計・可視化し、分析レポートとして納品するサービス。

投資助言や売買判断ではなく、データ処理、検証、可視化、レポート作成を行う。

一言で言うと

手元にある金融データを、Pythonで見やすい表・グラフ・レポートに変換します。

対応できる仕事

  • CSV / Excelデータの整形
  • 価格データの時間帯別・曜日別分析
  • バックテスト結果の集計
  • PF、勝率、最大ドローダウン、損益推移の整理
  • 取引履歴・約定履歴の損益分析
  • 暗号資産APIデータの取得・CSV化
  • Hyperliquid fillsの集計
  • グラフ画像の作成
  • Markdown / Word / PDF形式の簡易レポート作成
  • 再実行用Pythonスクリプトの納品

対応しない仕事

  • 個別銘柄の売買判断
  • エントリー価格や利確・損切りラインの助言
  • 利益保証
  • 自動売買の本番発注
  • APIキーや秘密鍵を預かる運用
  • 投資顧問契約にあたる個別助言

ポートフォリオ実例に使うもの

実例1: BTCUSD時間帯別大変動分析

BTCUSDの価格データを使い、日本時間で大きな変動が出やすい時間帯を集計。

見せ方:

  • 入力: BTCUSD M1データ
  • 処理: H1変換、3時間後・6時間後の大変動率を集計
  • 出力: 時間帯別テーブル、Markdownレポート

実例2: BTCUSD no-lookaheadバックテスト集計

BTCUSDのバックテスト結果を、未来データ参照を避ける設計で検証。

見せ方:

  • 入力: BTCUSD価格データ
  • 処理: シグナル生成、コスト反映、トレード集計
  • 出力: PF、勝率、最大ドローダウン、年別集計

実例3: Hyperliquid fills集計

Hyperliquidの約定履歴をBTCに絞り、close / open、buy / sell、closedPnl、推定エントリー時間を整理。

見せ方:

  • 入力: fills CSV
  • 処理: BTC抽出、損益集計、推定エントリー価格計算
  • 出力: 集計CSV、再現メモ、分析レポート
