発信・認知戦略02-ai-self-project-monetization/20_project_05_monetization_funnel.md

基本方針

このメディアの収益化は、広告収益を最初の目的にしない。

最初の目的は、自分の商品群へ読者・視聴者を流すこと。

収益導線は次の順番で作る。

  1. 実例コンテンツを見る
  2. 無料配布を受け取る
  3. AIセルフプロジェクト設計キットを買う
  4. 講座へ進む
  5. 個別相談へ進む
  6. 伴走またはコミュニティへ進む

導線全体

無料コンテンツ

媒体:

  • note
  • YouTube
  • Shorts
  • X

役割:

興味づけ、信頼構築、実例提示。

収益モデル

1. 自社商品販売

最優先。

商品:

  • 設計キット
  • 講座
  • 伴走
  • ラボ

2. 有料note

深掘り記事、リサーチ、制作ログを有料化する。

価格:

  • 500円
  • 980円
  • 1,980円

3. PDFレポート販売

シリーズごとにレポート化する。

例:

  • AIで金融分析プロジェクトを作るレポート
  • AIで古代史リサーチを商品化するレポート
  • AI自然栽培計画ワークブック

価格:

  • 1,980円
  • 2,980円
  • 4,980円

4. アフィリエイト

AIツール、Notion、動画制作ツール、学習教材など。

注意:

自分が使っているもの、信頼できるものだけ紹介する。

5. スポンサー

将来的に、AIツール、教育サービス、制作ツール、データ分析ツールのスポンサーを受ける。

最初は狙わない。

6. 受託・共同制作

実例メディアを見た人から、リサーチ、教材制作、動画制作、講座設計の依頼を受ける。
