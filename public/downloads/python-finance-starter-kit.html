ゴール

1つの金融データを選び、Pythonで読み込み、統計量を出し、2種類のグラフを作り、AIでレポート化する。

  • 投資助言ではなく分析学習として扱う
  • 平均・標準偏差・最大値・最小値を説明できる
  • グラフを見て傾向と限界を書ける

Step 1. 分析テーマを決める

初心者向け

BTCの日次終値を使って、日次リターンの平均とばらつきを見る。

中級向け

曜日別・時間帯別に変動率を集計し、いつ値動きが大きいか確認する。

発信用

統計結果とグラフを、noteやブログ用の学習レポートに変換する。

Step 3. Pythonコード

import pandas as pd
import matplotlib.pyplot as plt

# 1. CSVを読み込む
df = pd.read_csv("market_data.csv", parse_dates=["date"])
df = df.sort_values("date")

# 2. 日次リターンを計算する
df["return"] = df["close"].pct_change()

# 3. 統計量を出す
stats = {
    "平均リターン": df["return"].mean(),
    "標準偏差": df["return"].std(),
    "最大上昇": df["return"].max(),
    "最大下落": df["return"].min(),
    "サンプル数": df["return"].count(),
}
print(pd.Series(stats))

# 4. グラフを描く
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
df.plot(x="date", y="close", ax=axes[0], title="Close Price")
df["return"].hist(ax=axes[1], bins=12)
axes[1].set_title("Daily Return Distribution")
plt.tight_layout()
plt.show()

Step 4. 結果記入シート

項目結果初心者向け説明
平均リターン期間中、1日あたり平均でどれくらい動いたか。
標準偏差日々の値動きのばらつき。大きいほど上下に振れやすい。
最大上昇最も大きく上がった日の変化率。
最大下落最も大きく下がった日の変化率。
サンプル数分析に使った有効データ数。少なすぎると信頼しにくい。

Step 5. グラフの見方

01

価格推移

上昇・下落の方向だけでなく、どこで急に動いたかを見る。

02

分布

多くの日が中心に集まるか、端の大きな変動が多いかを見る。

03

限界

過去データだけでは未来を断定できない。期間とサンプル数を書く。
